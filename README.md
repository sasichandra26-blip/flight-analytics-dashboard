# ✈️ Flight Analytics Dashboard — Power BI

## 📌 Project Overview

SkyTrack Analytics is an interactive Power BI dashboard designed to analyze flight operations, airline performance, delays, and cancellations.

The dashboard presents key flight metrics through interactive visualizations and filters to support data-driven analysis.

## 🎯 Project Objectives

- Analyze total flight operations.
- Compare airline performance.
- Examine flight delays and arrival delay patterns.
- Track flight cancellations.
- Explore flight data using interactive slicers.

## 📊 Dashboard Pages

1. **Home** — Project landing page and navigation.
2. **Overview** — High-level flight performance metrics.
3. **Airline Analysis** — Airline-level comparisons.
4. **Delay & Cancellation Analysis** — Flight delays and cancellations.

## 🛠️ Tools & Skills

- Microsoft Power BI
- DAX (Data Analysis Expressions)
- Data modeling
- Data visualization
- Interactive dashboard design
